Abstract

The growing popularity and capacity of generative models have eroded the distinction between human and machine-generated content, motivating a growing body of work on detection across text, images, and audio. Most available detectors are either commercial software or, if open-source, come with incompatible codebases with bespoke preprocessing, evaluation protocols, and evaluation metrics, which make their adoption, fair comparison, and reproduction quite difficult.

To address this critical gap, we introduce DetectZoo, a first-of-its-kind, extensible toolkit designed to provide a unified interface for AI-generated content detection across text, audio, and image modalities. DetectZoo standardizes the complete empirical pipeline, from data ingestion and preprocessing to model assessment, offering researchers a cohesive framework to benchmark state-of-the-art detectors systematically. DetectZoo provides reference implementations of 61 detectors, native loaders for 22 benchmark datasets, and a standardized evaluation pipeline that reports multiple metrics through a common interface. Each detector is self-contained yet accessible through the same interface, automatically caches pretrained weights, and reproduces the original published results.

What is DetectZoo?

Detection methods for AI-generated content live in entirely separate ecosystems. Each new method is typically released as a standalone codebase with its own preprocessing, datasets, and metrics. This fragmentation produces three obstacles: (1) lack of fair comparison, (2) reproducibility barriers, and (3) no cross-modal perspective. DetectZoo aggregates 61 detection methods across three modalities into a single codebase with one consistent interface, paired with 22 benchmark datasets and a standardized evaluation pipeline.

Reproducible

Clean, standardized implementations of published detectors, validated against the authors' originally reported results.

Accessible

Load and run any detector with a single function call. Pretrained weights and datasets download and cache automatically.

Extensible

Adding a new detector takes a single file: subclass BaseDetector, implement predict, and register with a decorator.

One API, every modality

Every predict() call returns the same DetectionResult — a score, a label, a confidence, and detector-specific metadata. 

from detectzoo import load_detector, list_detectors

# Detect AI-generated text
detector = load_detector("fast_detectgpt")
result = detector.predict("Large language models are transforming many fields.")
print(result.score, result.label, result.confidence)

# Detect AI-generated images
detector = load_detector("aeroblade")
print(detector.predict("image.png").label)   # "ai" or "human"

# Detect synthetic audio
detector = load_detector("rawnet2")
print(detector.predict("speech.wav").score)

# Discover what's available
print(list_detectors("text"), list_detectors("image"), list_detectors("audio"))

Benchmark detectors head-to-head on any labelled dataset:

from detectzoo import load_detector
from detectzoo.datasets import HC3Dataset
from detectzoo.benchmarks import BenchmarkEvaluator

dataset = HC3Dataset(subsets=["finance"])            # auto-downloads + caches
evaluator = BenchmarkEvaluator(dataset)
evaluator.run_and_print([
    load_detector("log_likelihood"),
    load_detector("entropy"),
    load_detector("fast_detectgpt"),
])   # prints accuracy, precision, recall, F1, AUROC

Reproducing published results

For each detector with publicly reported metrics, DetectZoo re-runs the original experimental setup and validates its outputs against the authors' reported numbers. We reproduce findings from four recent studies across six benchmark scenarios. The standardized pipeline tracks the originals closely — for example, on cross-task XSum detection our reproduced average AUROC of 0.6438 tightly mirrors the published 0.6335.

Add your own detector in one file

from detectzoo.detectors import BaseDetector
from detectzoo.core.registry import register_detector

@register_detector("my_detector")
class MyDetector(BaseDetector):
    modality = "text"   # or "image" or "audio"

    def predict(self, input_data):
        score = 0.0   # your detection logic here
        return self._make_result(score)

# Immediately available everywhere:
from detectzoo import load_detector
detector = load_detector("my_detector")
